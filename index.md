      <li>Confidence blending to merge surfel + screen-space lighting</li>

<p>
This project re-implements <strong>surfel-based GI</strong> (as used in Frostbite / GIBS) and introduces the <strong>Near-Far Surfel Sphere (NFSS)</strong>, a hybrid data structure combining surfels with screen-space approximations. It reduces overspawning in dense geometry while maintaining lighting quality.

</p>

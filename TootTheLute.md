 ## Welcome to another page

#### Description
An action rhythm battler combining Hades-style action gameplay with the rhythm system of games like Beats Pers Minute (BPM).
#### Role And Responsiblities
Led a team of junior developers on their first project. Established scope, production workflow, and delivery schedule.  
* Singlehandedly managed **code and asset integration**. 
* Designed and implemented a **full rhythm gameplay system**, including beat detection and timing-based input grading. 
* Developed a custom **visual beat slider** synced with audio to provide visual cues. 
* Created a modular Beatmap data structure, allowing designers to add new tracks easily via structured data inputs. 
* Added dynamic audio/input and audio/visual **latency calibration screen**. 
* **Modular enemy AI** based on boids algorithm with a **custom obstacle avoidance behaviour**
